# Accuracy

Data: `results/domain_accuracy_summary.csv` and `results/holm_significance_summary.csv`.
Means and sample SDs are calculated across five runs. Significance uses paired t tests with Holm correction and a figure annotation threshold of 0.01.

- Rebuild data: `scripts/build_accuracy_summary.py`
- Plot: `scripts/plot_accuracy_panels.py`
- Verify: `scripts/validate_experiment.py`
